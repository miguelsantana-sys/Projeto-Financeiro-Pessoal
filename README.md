#  MS Financeiro Pessoal

Um sistema de gerenciamento financeiro pessoal desenvolvido para facilitar o controle de receitas, despesas e organização da vida financeira.

##  Sobre o projeto

O MS Financeiro Pessoal foi desenvolvido com o objetivo de criar uma interface simples, moderna e intuitiva para que o usuário possa acompanhar sua situação financeira.

##  Funcionalidades

-  Cadastro de receitas
-  Cadastro de despesas
-  Dashboard financeiro
-  Visualização dos gastos
-  Organização das movimentações
-  Controle do saldo

##  Tecnologias utilizadas

- Python
- HTML
- CSS
- SQL
